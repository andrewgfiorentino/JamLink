# Public repository status

As of 2026-08-19, this repository is the public GPL source and release-history repository for the JamLink versions that were published here through `v0.4.8-test`.

Active JamLink development is no longer conducted in this public repository. The last active-development commit before that transition is:

`6b80d30a09f097668d01869f29c73b64bf3effb5`

A named preservation branch, `gpl-public-snapshot-2026-08-19`, points to that public-development boundary.

## What this means

- Source code and releases already published under GPL-3.0-or-later remain available under those GPL terms. Nothing in this transition revokes or narrows rights already granted to recipients.
- This repository is being retained so the public history, corresponding source, licence texts, notices, tags, and provenance for those releases remain available.
- New feature development, implementation details, internal design work, and development roadmaps are no longer published here as they are created.
- Public bug reports and release feedback may still be accepted here, but unsolicited code pull requests are not currently being accepted into the active product line.
- Any future JamLink distribution will carry the licence notices, source availability, and third-party compliance materials required by the licences that apply to that distribution.
